# Ui/

Общий слой шелла. `Design.qml` — эталонный файл: цвет, шрифт, форма,
движение и масштаб в одном месте. Остальное — компоненты, собранные из него.

## Правило

**В файле попапа не появляется голый `Rectangle` с hex-цветом и собственной
`duration`.** Нужен новый визуальный элемент — он сначала заезжает сюда.

Проверяется глазами по диффу за две секунды. Именно отсутствие этого правила
развело одиннадцать попапов в одиннадцать частных дизайн-систем: 72 разных
длительности анимации, 16 кеглей, 10 радиусов, 303 инлайновых `Rectangle`.

## Использование

```qml
import "../Ui"

PopupShell {
    ColumnLayout {
        anchors.fill: parent
        spacing: Design.s(Design.space.xl)

        Badge { text: "NEW UPDATE AVAILABLE"; tone: Design.ok }
    }
}
```

### Состав

| | |
|---|---|
| **Рамка** | `PopupShell` — окно попапа, Escape, `close()`, `scriptDir` |
| | `Card` — озаглавленная карточка |
| | `ScrollArea` — прокрутка со скроллбаром шелла |
| **Примитивы** | `Label` — текст на шкале кегля |
| | `Icon` — nerd-глиф на той же шкале |
| | `Clickable` — `MouseArea` с дефолтами шелла |
| **Контролы** | `Slider` · `Toggle` · `Pill` · `Stepper` |
| **Строки** | `Badge` — статусная пилюля |
| | `DeviceRow` — имя / деталь / значение |

`Label` — самая нагруженная вещь тут: 374 из 419 текстовых блоков в попапах
повторяли одну тройку «семейство + кегль + цвет» вручную, по четыре строки.

Список растёт **по факту спроса** — из того, что реально понадобилось
очередному переезжающему попапу, а не списком наперёд. Геометрия конкретного
контрола (дорожка тумблера 40×24) остаётся числом внутри него: токен на такое
был бы уже абстракцией ради абстракции.

### Начертания

`regular` 400 · `medium` 500 · `semibold` 600 · `bold` 700.

`bold` — потолок намеренно. Попапы тянулись к `Font.Black` 51 раз, но
JetBrains Mono заканчивается на ExtraBold: веса 900 в семействе нет, и Qt
каждый раз подставлял ближайший или синтезировал. Проверить:
`fc-list "JetBrainsMono Nerd Font" | sed 's/.*://'`

## Масштабирование

`Design` отдаёт **немасштабированные** числа и сам же умеет их масштабировать:

```qml
font.pixelSize: Design.s(Design.font.body)
```

Масштаб глобальный — `Main.qml` это одно окно на одном активном экране, поэтому
per-screen ничего бы не дал. Если когда-нибудь понадобится мультимонитор с
разным DPI, масштаб переезжает на `PopupShell`.

Длительности и кривые не масштабируются никогда: 250 мс это 250 мс на любом
мониторе.

## Шрифты — только через токен

`Design.font.mono` / `Design.font.icon` / `Design.font.sans` — или, что проще,
`Label` и `Icon`, которые их уже выставили. Прямые строки запрещены: попапы просили `"Iosevka Nerd Font"` 120 раз и `"JetBrains Mono"`
310 раз, а установщик не ставит ни того, ни другого имени —
`ttf-jetbrains-mono-nerd` даёт семейство `JetBrainsMono Nerd Font`. Оба
разрешались через фолбэк fontconfig. Проверить у себя: `fc-match "<имя>"`.

## Цвет

Роли, а не оттенки. Имя отвечает на вопрос «зачем он тут», а не «какой он».

| Роль | Назначение |
|---|---|
| `ground` | фон окна |
| `sunken` | углубление: треки слайдеров, шапки |
| `surface` | тело попапа или панели |
| `raised` | карточка на панели |
| `hover` | наведение, заливка контрола |
| `active` | нажатое, выбранная строка |
| `text` / `textDim` / `textFaint` | текст по убыванию важности |
| `line` | границы |
| `accent` / `onAccent` | акцент и текст **на** акценте |
| `accentAlt` | второй уровень выделения |
| `ok` / `warn` / `danger` | **статус, не украшение** |
| `veil` / `veilStrong` / `veilBold` | полупрозрачный слой поверх стекла |

Два правила:

1. Акцент один — `accent`. Если элемент хочется покрасить в зелёный «чтобы было
   красиво», он красится в `accent`.
2. `ok` и `warn` намеренно **не** выводятся из обоев. Иначе на красных обоях
   «подключено» станет красным, а «заряжается» — оранжевым. `danger` следует за
   матугеном: роль `error` в Material You и так гарантированно читается тревожно.

### Что значит «один акцент» на практике

`VolumePopup` красил три вкладки в три оттенка, причём один из них был `ok` —
статусный цвет в роли украшения. Вкладка и так подписана словом, так что
оттенок кодировал то же самое второй раз. Стало: активный контрол — `accent`,
всегда.

`accentAlt` при этом остался на строке микрофона — и это не исключение из
правила, а его прямое применение. Микрофон виден **одновременно** с основным
регулятором, то есть это второй уровень выделения, а не вариативность.

Проверка: если два цвета никогда не видны на экране вместе — это вариативность,
и второй лишний.

### Veil — слой поверх стекла

Попапы писали его буквальным белым с семью разными альфами (`#05ffffff` …
`#33ffffff`) под одну идею. Буквальное белое вдобавок инвертируется на светлой
палитре от матугена — тонирование через `text` следует теме.

Три ступени по присутствию слоя, годятся и как заливка, и как волосяная линия:

| | | |
|---|---|---|
| `veil` | 0.05 | покой: карточка, ложе слайдера |
| `veilStrong` | 0.10 | наведение, линия на стекле |
| `veilBold` | 0.16 | утверждение: включённый тумблер, разделитель |

## Миграция

`Design` экспортирует старые имена Catppuccin (`base`, `mauve`, `surface0`…)
как алиасы на роли. Попап может перейти на `Design.` до того, как в нём
переименуют цвета — переключение и переименование делаются раздельно.

Когда на старые имена никто не ссылается, блок в конце `Design.qml` удаляется:

```bash
grep -rn "Design\.\(base\|mantle\|crust\|surface[012]\|overlay\|blue\|mauve\|sapphire\|pink\|peach\|yellow\|green\|teal\|red\|maroon\|subtext\)" --include='*.qml' ..
```

## Критерий, что миграция идёт правильно

**Попап после переноса должен похудеть.** Если файл не стал короче — токенов
не хватает или они не те, и это видно сразу, а не через три попапа.

Оговорка, купленная на канарейке: считать строки честно можно только при
сохранении стиля исходника. Первый прогон `UpdaterPopup` дал 417 → 429, потому
что одиннадцать однострочных блоков анимации были развёрнуты в многострочные.
Содержательно файл при этом уже схлопнулся — 52 захардкоженных решения до 3.
После возврата к компактному стилю: **417 → 356**.

Поэтому мерить стоит обе величины:

```bash
grep -c '#[0-9a-fA-F]\{6\}\|Qt\.rgba\|duration: [0-9]\|font.family: "' попап.qml
```
